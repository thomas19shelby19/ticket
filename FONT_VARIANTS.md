# Варіанти шрифту для динамічних значень

На основі порівняння з еталонним скріншотом найближчим кандидатом є **Comfortaa Bold**. У поточній версії №1 саме він встановлений для динамічних значень сторінки 4.

1. **Comfortaa Bold** — поточний рекомендований варіант.
2. **Comfortaa Regular** — тонший варіант для порівняння.
3. **Comfortaa Bold, трохи менший** — варіант для перевірки висоти цифр/таймера.

Файл `font_variants_1_2_3.png` додається окремо до повідомлення.

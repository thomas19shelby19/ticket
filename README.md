# Квиток — фінальна версія для GitHub Pages / iPhone 12

Ця версія є контрольним фінальним варіантом після покрокового звірення сторінок 2 і 4 з наданими еталонними скріншотами 1170×2532.

## Логіка
- 3 цифри номера транспорту → «КП Вінницька транспортна компанія».
- 4 цифри → «КП Вінницька транспортна компанія автобуси».
- Порожній номер → повторне відкриття збереженого квитка, якщо він існує.
- Номер транспорту передається через localStorage.
- QR-сканер → сторінка кількості квитків → оплата → фінальний квиток.
- Кількість квитків мінімум 1, кнопки +/−.
- Вартість на сторінці кількості та сторінці оплати — 25 UAH за один квиток.
- На фінальному квитку сума залишається 25 UAH відповідно до погодженого ТЗ, незалежно від кількості квитків.
- Дата і час фінального квитка — момент підтвердження оплати.
- Термін дії — 1 година; таймер зупиняється рівно на 00:00.
- Після підтвердження оплати один раз показується зелена плашка «Оплата успішна».
- Кнопка Google Pay, Apple Pay і карткова форма збережені в існуючій демонстраційній логіці.

## Еталонний дизайн
- Базовий розмір сторінок 2/4: 390×777 CSS px — під еталон iPhone 12.
- Растрові елементи `ticket_closed.png`, `ticket_open.png` і `modal_sheet_clean.png` використовуються без масштабування по ширині: 358×514 CSS px для квитка та 390×658 CSS px для модального аркуша.
- Позиції динамічних елементів сторінки 4 задані статично за координатами еталонного скріншота.
- Для автобуса окремо зроблена розширена плашка «Квиток Проїзд(Автобус)», щоб текст не виходив за межі.
- Вся область зображення чоловічка/QR є єдиною великою кнопкою та перемикає стани в обидві сторони.
- Вікно «Додаткові дані» підняте до еталонного положення; затемнення покриває весь вебперегляд.
- Шрифти проєкту: надані `Comfortaa-Regular.ttf` та `Comfortaa-Bold.ttf`.
- Фон: `#B4D5D2`; зелений акцент: `#64A33B`.
- Орієнтація — portrait.

## Важливо
Не змінювати геометрію сторінок 2 і 4 без прямого погодження. Якщо потрібно виправити один елемент, змінюється лише цей елемент.

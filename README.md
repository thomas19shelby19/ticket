# Квиток — фінальна тестова версія

## Структура
- `index.html` — Number_ticket: номер транспорту.
- `scanner.html` — QR-сканер; кнопка «Відкрити у Safari» переходить на вибір кількості квитків.
- `page2.html` — кількість пасажирів і автоматичний розрахунок суми по 25 грн.
- `payment.html` — тестова сторінка оплати; Google Pay та Apple Pay переходять далі без реальної оплати.
- `page4.html` — фінальний квиток, QR/логотип, додаткові дані та таймер на 1 годину.
- `manifest.json` — режим вебпрограми та вертикальна орієнтація.
- `images/` — усі надані зображення.

## Правила транспорту
- 3 цифри → `КП Бабчинецька транспортна компанія`
- 4 цифри → `КП Бабчинецька транспортна компанія автобуси`

## Ціна
1 квиток = 25 грн. Кнопка «−» не дозволяє зменшити кількість нижче 1.

## Важливо
QR-сканер використовує бібліотеку `html5-qrcode` із CDN (Content Delivery Network — мережа доставки контенту). Для камери потрібен HTTPS, тому GitHub Pages підходить.

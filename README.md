# Квиток — фінальна версія

Еталонна версія проєкту для iPhone 12.

## Логіка
- 3 цифри номера транспорту → КП Вінницька транспортна компанія.
- 4 цифри → КП Вінницька транспортна компанія автобуси.
- Порожній номер → повторне відкриття збереженого квитка, якщо він існує.
- Номер транспорту передається через localStorage.
- QR-сканер → сторінка кількості квитків → оплата → фінальний квиток.
- Кількість квитків мінімум 1, кнопки +/-.
- Ціна на сторінці кількості та сторінці оплати — 25 UAH за квиток.
- На фінальному квитку сума відображається як 25 UAH згідно з погодженим ТЗ, незалежно від кількості квитків.
- Час квитка — момент підтвердження оплати.
- Термін дії — 1 година, таймер зупиняється на 00:00.
- Дані квитка зберігаються для повторного відкриття через історію браузера.
- Google Pay, Apple Pay та карткова форма залишені в існуючій демонстраційній логіці.

## Дизайн
- Сторінка 2 відтворена за наданим еталонним скріншотом 1170×2532.
- Сторінка 4 використовує надані точні еталонні зображення ticket_closed.png і ticket_open.png.
- Шрифт: наданий Comfortaa Regular/Bold.
- Фон: #B4D5D2.
- Для сторінки 4 не змінюються погоджені розміри, розташування, кольори та графічні елементи.
- Кнопка i відкриває «Додаткові дані».
- «Переглянути QR» перемикає фінальний квиток на відкритий QR-стан.
- Орієнтація — portrait.

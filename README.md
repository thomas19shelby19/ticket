# Квиток — фінальна версія

Фінальна збірка для завантаження на GitHub Pages.

## Основна логіка
- 3 цифри номера транспорту → `КП Бабчинецька транспортна компанія`.
- 4 цифри → `КП Бабчинецька транспортна компанія автобуси`.
- Після «Далі» відкривається QR-сканер; QR або «Відкрити у Safari» веде на сторінку вибору кількості квитків.
- Вартість одного квитка — 25 UAH.
- Після оплати зберігаються час оплати, сума, кількість квитків і номер транспорту.
- Таймер дійсний 1 годину від моменту оплати.
- Якщо на 1-й сторінці поле «Номер» залишити порожнім і натиснути «Далі», відкривається останній збережений квиток лише якщо його 1-годинний строк дії ще не минув.
- Після повторного входу актуальні дані останньої оплати (номер транспорту, кількість, сума, дата і залишок часу) беруться зі збережених даних.
- Після завершення 1 години повторне відкриття через порожнє поле не створює новий квиток.
- На сторінці квитка для автобуса відображається `Проїзд(Автобус)`.
- Центральне зображення перемикається між логотипом і тестовим QR-кодом.
- Кнопка `i` відкриває додаткові дані.
- `manifest.json` має `orientation: portrait` для вертикального режиму вебпрограми.

## Важливо для GitHub Pages
Завантажити **вміст папки `ticket_v5`**, щоб `index.html` лежав у корені опублікованого сайту.
